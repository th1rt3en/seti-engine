# Rules spec (base game)

Status: **draft for owner review** (Phase 1, written 2026-10-12). Derived from `docs/rules/SETI-rulebook-EN-2024-09-17.pdf`, the official FAQ `docs/rules/seti-faq-printer-friendly.pdf` (see `faq.md`), the alien rule sheets `docs/rules/SETI_Alien_rule_sheets_(EN).pdf`, the owner's card checks, and the rival card transcription. The Space Agencies expansion is out of scope for now (PLAN.md D22).

## Conventions

- Every rule has an ID such as `SETUP-12` or `ALIEN-EXE-07`, with the rulebook page it comes from (`p.N`; `sheet N` for the alien rule sheets). IDs never change once assigned.
- Rule text restates the rulebook; where the rulebook leaves a gap, the rule says so and points to an ambiguity `A-NNN` in `ambiguities.md`. Agents do not guess (CLAUDE.md rule 3).
- Board layouts, rewards, tile values and card data are data, not rules. They are listed as data tasks (`BOARD-xx`, `ALIEN-DATA-xx`, `SOLO-DATA-xx`) and verified by the owner.
- `rules-index.md` is generated by `python tools/spec/build_index.py`. The script fails if an ID is defined twice, referenced but not defined, or an ambiguity is referenced but missing.

## What is still needed before the engine can be written

1. Owner rulings on the open ambiguities in `ambiguities.md` (A-003 to A-014 plus A-001 and A-002). The ones that change play are A-001, A-002, A-003, A-005, A-008, A-010.
2. Board data (BOARD-01 to 08): the solar system, the 8 sector slots, the planetary board and the tech board. This is the largest piece of data work and needs the board images to be read carefully and checked by the owner.
3. Data for tech tile bonuses, gold tile values, alien board spaces, Mascamite samples, solo objective tasks and rival boards.
4. The card definitions: `data/card-definitions.json` is the readable draft (repo data plus the owner's notes). It has to be turned into the engine's structured effect format in Phase 2, and the 81 re-checked cards need the owner's confirmation.
